# Changelog

## 1.5.0 — 2026-11-29

- Check GitHub Releases for updates automatically or from the menu bar.
- Let users opt into automatic download and installation.
- Verify the signed update feed and download with Sparkle.

## 1.4.0 — 2026-11-28

- Add settings for custom brightness shortcuts, restoring the defaults, and choosing the adjustment step.
- Start Display Brightness at macOS login when enabled in Settings.
- Use the Display Brightness logo as the macOS app icon.

## 1.3.1 — 2026-11-26

- Adopt Display Brightness as the app, installer, and repository name.
- Keep existing keyboard and display selection preferences when upgrading.

## 1.3.0 — 2026-11-26

First public release.

- Discover DDC/CI displays at launch, after reconnecting, and after waking the Mac. Choose a preferred monitor from the menu bar.
- Adjust hardware brightness with F1/F2 or Control + Option + Up/Down. Show the selected monitor's reported percentage and black out its picture at 0%.
- Build from source on Apple Silicon. The distribution script supports Developer ID signing, notarization and DMG packaging.
