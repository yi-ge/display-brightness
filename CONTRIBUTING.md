# Contributing

Build with `./build.sh` on an Apple Silicon Mac with the Xcode Command Line Tools. Install m1ddc to test on a compatible display.

For display or keyboard changes, test the standard brightness keys, the alternative shortcuts, and recovery from 0%. For display discovery changes, check selection after connecting, disconnecting, and reconnecting a display. Record the macOS version, display model, connection type, and relevant DDC readings in the pull request.

Keep [README.md](README.md) and [README_CHS.md](README_CHS.md) in sync when changing usage or installation. An issue report can include the app version, macOS version, display model, cable or adapter, and steps to reproduce the behavior.
